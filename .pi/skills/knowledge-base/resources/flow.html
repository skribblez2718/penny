Bounded repairs & honest exhaustion

  • Repairs fire on the result, never on a label: lint → compose on an error-severity finding (synthesis_gap), verify → compose on an unsupported claim (validation_gap), and any agent phase → itself on an incomplete result (malformed_result). Each is bounded by the run's iteration budget.
  • Budget spent → no fake pass. The finding is carried forward as unresolved and the machine proceeds on the forward path; the gate still sees an honest candidate set.
  • refine (host, at the gate) re-enters at compose — the candidate must change where it can change, and is re-linted and re-verified before the gate is offered again.

Authority & privacy seams

  • Uniform seam (arrows omitted for legibility): operator cancellation from any non-terminal state ends the run at the cancelled terminal (met = false). Same documented-omission convention as the research diagram's abort seam.
  • initialize (engine, before ingest): claims the source capabilities and admits the source objects — all-or-none, so the approval path publishes exactly what the agents saw. A drifted source refuses here, before any agent read.
  • Child sessions read only through host-closed readers (phase brief, admitted source snapshot, allowed prior-phase output) and submit exactly one typed result; a path, root, or approval decision never reaches a child, and no private body returns to the parent.
