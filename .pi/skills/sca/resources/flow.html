SCA — active workflow

Strict machine-readable mirror of SCA_FLOW for one bounded, immutable repository security analysis.

Host-owned scanner/graph preparation feeds focused alert and no-alert selection, falsifiable hypotheses, discriminating evidence, supported dispositions and learning assessment. One accepted set produces full JSON, Markdown and SARIF, reviewed by Carren and independently verified by Vera. Typed cognitive rejections permit fresh same-stage drafts under actual operator policy, without invented finite caps, never host-authored fixes or external replay. Missing material capability or evidence stays INCOMPLETE, never safe PASS.
