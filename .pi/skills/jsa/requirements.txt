# jsa skill runtime dependencies
#
# These are the Python packages required to run the jsa skill's analysis tools.
# The FSM now lives in the shared orchestration engine (apps/orchestration), so
# python-statemachine is no longer a skill dependency. External CLI tools
# (semgrep, jsluice, playwright, tree-sitter-cli) are installed separately.

# AST-based JS parsing (tree-sitter helpers in splitter.py, used by
# structure_analysis).
# The code uses the Query/QueryCursor API, which requires tree-sitter >= 0.23
# (verified runtime: tree-sitter 0.26.x, tree-sitter-javascript 0.25.x). Keep
# tree-sitter-javascript on a grammar-ABI-compatible release of the same line.
# The splitter lazy-imports these and falls back to token-based chunking
# if they are missing, so installation is recommended but not strictly
# required for the orchestrator to function.
tree-sitter>=0.23.0
tree-sitter-javascript>=0.23.0
